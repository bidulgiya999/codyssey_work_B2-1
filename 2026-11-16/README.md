# 2026-11-16 콘솔 가계부 실습 기록

VS Code의 PowerShell 터미널에서 거래 추가부터 카테고리 관리까지 실행한 작업 기록입니다. 각 단계의 기능, 입력 명령, 확인 결과와 평가 설명을 정리했습니다. 이번 기록의 마지막 단계는 **사용 중인 `food` 카테고리 삭제 차단 확인**입니다.

프로그램 소스는 저장소 루트의 [budget_app](../budget_app)에 있습니다. 아래 명령은 `budget_app`이 있는 프로젝트 루트에서 실행합니다. 이 문서가 있는 `2026-11-16` 폴더 안에서 실행하는 것이 아닙니다. 전체 기능과 저장 구조는 [기존 README](../README.md)를 참고하세요.

## 1. VS Code 실행 준비

이 컴퓨터의 작업 폴더는 `C:\Users\1234v\Desktop\calculator`입니다. VS Code의 **파일 → 폴더 열기**로 해당 폴더를 열고 **터미널 → 새 터미널 → PowerShell**을 선택합니다.

```powershell
cd "C:\Users\1234v\Desktop\calculator"
$ledgerPython = 'C:\Users\1234v\AppData\Roaming\uv\python\cpython-3.15-windows-x86_64-none\python.exe'
& $ledgerPython -m budget_app --help
```

- `$ledgerPython`은 이 컴퓨터에 설치된 Python의 실행 경로입니다. 새 터미널을 열면 다시 설정합니다.
- 다른 컴퓨터는 설치된 Python 경로로 바꾸거나 `python -m budget_app ...`로 실행합니다.
- `PS C:\...>`는 터미널이 자동 표시하는 현재 위치입니다. 직접 입력하지 않습니다.
- 폴더로 이동할 때는 경로만 입력하지 않고 `cd "경로"`를 사용합니다.
- 명령 끝에 `\`를 붙이지 않습니다. 명령을 한 줄씩 실행합니다.
- 명령은 `PS C:\...>`에서 입력하고, `날짜:` 등 질문이 나오면 답만 입력합니다.

**확인 결과:** 도움말에 `add`, `list`, `search`, `summary`, `budget`, `category`, `update` 등의 명령이 표시되었습니다.

**설명 멘트:**
> Python 표준 라이브러리로 만든 콘솔 가계부입니다. 도움말로 명령을 확인할 수 있고, 데이터는 기본 data 폴더에 저장됩니다.

## 2. 수입 거래 추가

### 기능과 작업

대화형 입력으로 2026년 11월 월급을 등록했습니다. `add` 명령은 한 번만 실행하고, 이후에는 각 질문에 해당하는 값만 입력합니다.

```powershell
& $ledgerPython -m budget_app add
```

| 질문 | 입력한 값 |
| --- | --- |
| 날짜 | `2026-11-16` |
| 타입 | `income` |
| 카테고리 | `salary` |
| 금액 | `3000000` |
| 메모 | `이번달 월급` |
| 태그 | `기타` |

**확인 결과:** 저장 완료 메시지와 고유 거래 id가 출력되었습니다.

**설명 멘트:**
> 거래 추가는 날짜, 타입, 카테고리와 금액 등을 대화형으로 입력받습니다. 입력을 검증한 후 저장하고 거래마다 고유 id를 부여합니다.

### 실습 중 발생한 오류와 해결

처음에는 날짜 질문에 실행 명령을 입력해 날짜 형식 오류가 발생했습니다. 해당 거래는 저장되지 않았습니다. 다시 `add`를 실행하고 날짜 질문에 `2026-11-16`만 입력해 해결했습니다.

PowerShell의 명령 입력 줄에 `2026-11-16`만 입력하면 뺄셈으로 계산되어 `1999`가 나옵니다. 날짜는 반드시 프로그램이 `날짜(YYYY-MM-DD):`를 물어볼 때 입력합니다.

## 6. 예산 설정과 월별 요약

### 명령

```powershell
& $ledgerPython -m budget_app budget set --month 2026-11 --amount 10000
& $ledgerPython -m budget_app summary --month 2026-11 --top 3
```

### 기능과 확인 결과

11월 예산을 10,000원으로 저장하고 요약을 실행했습니다. 월급과 점심 거래를 각각 한 건씩 저장한 시점의 결과는 다음과 같습니다.

| 항목 | 결과 |
| --- | ---: |
| 총수입 | 3,000,000원 |
| 총지출 | 15,000원 |
| 잔액 | 2,985,000원 |
| 월 예산 | 10,000원 |
| 사용률 | 150.0% |
| 초과액 | 5,000원 |

예산 초과 경고가 정상적으로 출력되는 것을 확인했습니다. `--top 3`은 지출 합계가 큰 카테고리를 최대 3개 표시합니다.

**설명 멘트:**
> 월별 수입, 지출과 잔액을 계산하고 카테고리별 지출 순위를 보여줍니다. 월 예산이 있으면 지출 기준 사용률을 표시하고 예산을 넘으면 경고합니다.

## 7. 거래 수정

### 거래 id 확인과 변수 설정

```powershell
& $ledgerPython -m budget_app list --limit 5
$expenseId = 'TX-699cbe9e3570482c8f9c48ab35060b9c'
```

위 id는 이번 실습에서 생성된 food 지출의 실제 id입니다. 새로 거래를 등록하거나 다른 데이터를 사용한다면 목록에서 해당 지출의 id를 확인해 바꿉니다. 월급 거래 id와 혼동하지 않습니다.

### 수정 및 확인

```powershell
& $ledgerPython -m budget_app update --id $expenseId --amount 12000 --memo 저녁
& $ledgerPython -m budget_app list --limit 5
```

**확인 결과:** 지출 금액이 15,000원에서 12,000원으로, 메모가 점심에서 저녁으로 변경되었습니다. 날짜, 타입, 카테고리와 태그는 유지되었습니다.

**설명 멘트:**
> 수정은 옵션 방식입니다. 거래 id를 기준으로 지정한 필드만 바꾸고, 지정하지 않은 정보는 유지합니다.

### 없는 id 오류 확인

처음에는 안내용 문구 `여기에_지출_id_붙여넣기`를 그대로 변수에 넣어 없는 데이터 오류가 발생했습니다. 실제 거래 id로 변수를 다시 설정한 후 수정에 성공했습니다. 안내용 문구는 실제 id가 아닙니다.

## 8. 잘못된 입력과 종료 코드 확인

### 명령

```powershell
& $ledgerPython -m budget_app update --id $expenseId --amount 0
$LASTEXITCODE
& $ledgerPython -m budget_app list --limit 5
```

### 확인 결과

- 금액 0을 거부하고 양수 정수 입력 안내와 힌트를 표시했습니다.
- 오류 직후 `$LASTEXITCODE`를 실행했을 때 `1`이 출력되었습니다.
- 목록에서 기존 금액 12,000원과 메모 저녁이 유지되는 것을 확인했습니다.

`$LASTEXITCODE`는 Python 명령이 종료한 직후 확인합니다. 이후 다른 Python 명령을 실행하면 해당 명령의 종료 코드로 바뀝니다.

**설명 멘트:**
> 금액 0은 유효하지 않으므로 오류 종료합니다. 스택트레이스 대신 원인과 해결 힌트를 출력하고, 실패한 수정은 기존 거래를 변경하지 않습니다.

## 9. 카테고리 추가·조회·삭제

### 추가

```powershell
& $ledgerPython -m budget_app category add
```

`카테고리명:` 질문에 `hobby`를 입력하고 Enter를 누릅니다.

### 조회

```powershell
& $ledgerPython -m budget_app category list
```

목록에 hobby가 추가된 것을 확인합니다.

### 사용하지 않는 카테고리 삭제

```powershell
& $ledgerPython -m budget_app category remove
```

`삭제할 카테고리명:` 질문에 `hobby`를 입력합니다. 삭제 후 `category list`로 목록에서 제외되었는지 확인합니다. 현재 저장된 카테고리 목록에는 hobby가 남아 있지 않습니다.

**설명 멘트:**
> 카테고리는 추가, 조회, 삭제가 가능합니다. 거래를 등록할 때는 이 목록에 존재하는 카테고리만 사용할 수 있습니다.

### 명령과 입력

```powershell

```

삭제할 이름에 `food`를 입력했습니다.

> 거래에서 사용 중인 카테고리는 삭제할 수 없도록 보호했습니다. 해당 거래를 다른 카테고리로 수정하거나 삭제한 뒤에만 카테고리를 삭제할 수 있습니다.

## 현재 시점의 정리

- 실행 확인 범위: 도움말 → 수입 추가 → 목록 → 검색 → 지출 추가 → 예산/요약 → 수정 → 잘못된 입력과 종료 코드 → 카테고리 관리와 삭제 보호.
- 이번 실습의 수입은 3,000,000원, 수정 후 지출은 12,000원입니다. 두 거래만 있다면 잔액은 2,988,000원, 예산 사용률은 120.0%, 초과액은 2,000원입니다. 추가로 거래를 등록하면 합계는 달라집니다.
- 저장 파일은 프로젝트 루트의 `data/transactions.jsonl`, `data/categories.jsonl`, `data/budgets.jsonl`입니다.
- 이 날짜 폴더는 실행 방법과 실습 결과를 기록합니다. 프로그램 소스와 실제 실행 데이터는 별도이며, 이 문서를 실행하거나 업로드하는 것만으로 거래가 추가되지는 않습니다.
- CSV 가져오기/내보내기, 거래 삭제, 백업은 기존 코드에 구현되어 있지만 이번 날짜의 단계별 실습 기록에는 포함하지 않았습니다.
