# VS Code PowerShell 명령어 모음집

이 안내는 **VS Code 안의 PowerShell 터미널** 기준입니다. 명령은 프로젝트 루트 `calculator`에서 실행합니다. `2026-11-16` 자료 폴더 안으로 이동해서 실행하는 것은 아닙니다. 문서는 사용법 모음이므로 모든 명령을 순서대로 다시 실행할 필요는 없습니다. 추가·수정·삭제·가져오기는 저장 내용을 변경합니다.

## 1. 시작하기: 터미널과 위치

1. VS Code의 **파일 → 폴더 열기 → 바탕 화면 → calculator**를 선택합니다.
2. **터미널 → 새 터미널**을 선택합니다. CMD라면 터미널 옆 `∨`에서 **PowerShell**을 새로 엽니다.
3. 아래 코드 상자의 명령만 한 줄씩 입력합니다.

```powershell
cd "C:\Users\1234v\Desktop\calculator"
$ledgerPython = 'C:\Users\1234v\AppData\Roaming\uv\python\cpython-3.15-windows-x86_64-none\python.exe'
& $ledgerPython --version
& $ledgerPython -m budget_app --help
```

`cd`는 작업 폴더를 바꿉니다. `PS C:\Users\1234v\Desktop\calculator>`는 터미널이 자동 표시하는 위치 안내이므로 입력하지 않습니다. 명령 끝에 `\`를 붙이지 않습니다. 날짜 질문이 나오면 실행 명령을 반복하지 말고 날짜만 입력합니다.

## 2. 왜 python 대신 앞에 기호와 변수를 붙이나요?

실제로는 **같은 Python 프로그램을 실행**합니다. 이 컴퓨터에서는 `python`이라는 짧은 명령이 Windows 별칭으로 연결되어 실행에 문제가 있었으므로, 설치된 Python의 정확한 위치를 직접 지정한 것입니다. VS Code에서 반드시 이 형식만 써야 하는 것은 아닙니다.

### 변수 설정 한 줄 해석

```powershell
$ledgerPython = 'C:\Users\1234v\AppData\Roaming\uv\python\cpython-3.15-windows-x86_64-none\python.exe'
```

| 부분 | 뜻 |
| --- | --- |
| `$` | PowerShell 변수임을 표시 |
| `ledgerPython` | 우리가 정한 변수 이름. Python 전용 예약어가 아님 |
| `=` | 오른쪽 값을 왼쪽 변수에 저장 |
| 작은따옴표 안의 경로 | 이 컴퓨터에 설치된 Python 실행 파일의 위치 |

이 줄은 **경로 문자열을 저장할 뿐 Python을 실행하지 않습니다.** 새 터미널을 열면 다시 설정합니다. 폴더를 옮겨도 같은 컴퓨터의 Python 경로는 그대로지만, 다른 컴퓨터에서는 그 컴퓨터의 Python 위치를 써야 합니다. 경로에 3.15가 있는 것은 설치 버전 때문이며 과제의 최소 조건은 Python 3.10입니다.

### 실행 한 줄 해석

```powershell
& $ledgerPython -m budget_app list --limit 5
```

| 부분 | 뜻 |
| --- | --- |
| `&` | PowerShell 호출 연산자. 변수/따옴표의 경로를 명령으로 실행 |
| `$ledgerPython` | 앞서 저장한 Python 실행 파일 경로 |
| `-m` | Python 옵션. 다음 이름의 패키지/모듈을 실행 |
| `budget_app` | 실행할 우리 가계부 패키지. `__main__.py`가 시작점 |
| `list` | 가계부에 요청할 목록 조회 명령 |
| `--limit 5` | 가계부 옵션. 최대 5건 출력 |

`-m`은 Python의 옵션이므로 하이픈 하나입니다. `--limit`, `--help` 등은 가계부 옵션이므로 하이픈 둘입니다. `&`와 `$`는 Python 코드가 아니라 PowerShell 문법입니다.

### 아래 세 가지는 같은 목적입니다

첫 번째 방식은 **python 명령이 올바른 Python에 연결된 경우** 사용합니다. 세 줄을 모두 실행할 필요는 없습니다.

```powershell
python -m budget_app --help
```

```powershell
& 'C:\Users\1234v\AppData\Roaming\uv\python\cpython-3.15-windows-x86_64-none\python.exe' -m budget_app --help
```

```powershell
& $ledgerPython -m budget_app --help
```

마지막 방식은 긴 경로를 매번 쓰지 않아 편리합니다. `$ledgerPython`만 입력하면 경로 문자열을 보여주고, `& $ledgerPython`은 그 실행 파일을 호출합니다. CMD는 이 문법이 다르므로 본 안내는 PowerShell로 통일합니다.

### 왜 파일 하나를 실행하지 않고 -m을 쓰나요?

가계부는 여러 모듈이 서로 연결된 패키지입니다. `-m budget_app`은 Python이 패키지 구조를 이해한 상태로 `budget_app/__main__.py`를 실행하게 합니다. `budget_app/cli.py` 하나를 직접 실행하는 방식은 상대 import 문제를 일으킬 수 있어 모듈 실행으로 통일합니다.

## 3. HELP 보는 방법

HELP는 도움말이라는 뜻이며 이 프로그램은 **소문자 `--help` 옵션**을 사용합니다. `HELP`라는 하위 명령은 없습니다.

```powershell
& $ledgerPython -m budget_app --help
```

이 명령은 프로그램 전체의 명령·전역 옵션을 보여주고 거래를 처리하지 않습니다. 도움말의 `usage`는 명령 사용 문법, `{...}`는 선택 가능한 명령, `[...]`는 보통 생략 가능한 항목입니다. 예를 들어 `--month MONTH`의 MONTH는 설명용 자리이며 실제로는 `2026-11` 같은 값을 입력합니다.

### 특정 명령만 자세히 보기

```powershell
& $ledgerPython -m budget_app add --help
& $ledgerPython -m budget_app list --help
& $ledgerPython -m budget_app search --help
& $ledgerPython -m budget_app summary --help
& $ledgerPython -m budget_app update --help
& $ledgerPython -m budget_app delete --help
& $ledgerPython -m budget_app import --help
& $ledgerPython -m budget_app export --help
& $ledgerPython -m budget_app backup --help
```

### 두 단계 명령의 도움말

```powershell
& $ledgerPython -m budget_app budget --help
& $ledgerPython -m budget_app budget set --help
& $ledgerPython -m budget_app budget show --help
& $ledgerPython -m budget_app category --help
& $ledgerPython -m budget_app category add --help
& $ledgerPython -m budget_app category list --help
& $ledgerPython -m budget_app category remove --help
```

예: 예산 설정 옵션이 기억나지 않으면 `budget set --help`로 필수 `--month`, `--amount`를 확인합니다. 도움말에는 입력 문법이 나오며, CSV 스키마와 전체 취소 정책 같은 상세 규칙은 README를 함께 확인합니다.

## 4. 어떤 상황에 어떤 명령을 쓰나요?

| 명령 | 사용하는 상황 | 하는 일 | 저장 거래 변경 |
| --- | --- | --- | --- |
| add | 월급/식비 등 새 기록을 남길 때 | 질문 입력 후 새 id로 저장 | 생성 |
| list | 최근 거래를 확인할 때 | 날짜 최신순 조회 | 없음 |
| search | 특정 월·카테고리·태그 등을 찾을 때 | 조건을 모두 만족하는 거래 조회 | 없음 |
| summary | 한 달 수입·지출·잔액을 볼 때 | 월 집계·지출 순위·예산 경고 | 없음 |
| update | 잘못 입력한 거래를 고칠 때 | 해당 id의 지정 필드 변경 | 수정 |
| delete | 불필요한 거래를 지울 때 | 해당 id 한 건 제거 | 삭제 |
| budget set | 월 지출 한도를 정할 때 | 월 예산 설정/갱신 | 예산만 변경 |
| budget show | 설정한 한도를 확인할 때 | 한 월 또는 전체 예산 조회 | 없음 |
| category add/list/remove | 분류 이름을 관리할 때 | 추가·목록·삭제, 사용 중 삭제 보호 | 카테고리만 변경 |
| export | 거래를 CSV로 전달하거나 볼 때 | 선택 기간의 거래를 CSV로 저장 | 없음 |
| import | 외부 CSV를 가계부에 넣을 때 | 검증 후 거래 일괄 등록 | 생성 |
| backup | 저장 파일 사본을 남길 때 | 세 파일의 ZIP 생성 | 원본 변경 없음 |

## 5. 거래 추가: add

```powershell
& $ledgerPython -m budget_app add
```

질문이 나오면 아래 값을 한 번에 붙여넣지 말고 **각 질문에 하나씩** 답합니다.

| 질문 | 예시 답 |
| --- | --- |
| 날짜 | 2026-11-16 |
| 타입 | expense |
| 카테고리 | food |
| 금액 | 15000 |
| 메모 | 점심 |
| 태그 | meal,work |

`income`은 수입, `expense`는 지출입니다. 날짜는 실제 날짜, 금액은 1~9223372036854775807의 정수, 카테고리는 등록된 이름이어야 합니다. 메모·태그는 Enter로 생략할 수 있습니다. 성공하면 `[저장 완료] id=TX-...`가 나오며 그 id로 수정·삭제합니다.

## 6. 목록과 검색: list / search

```powershell
& $ledgerPython -m budget_app list --limit 5
& $ledgerPython -m budget_app search --from 2026-11-01 --to 2026-11-30 --category salary --type income
& $ledgerPython -m budget_app search --q 월급 --tag 기타
```

list 기본값은 20건입니다. search는 기본 전체 결과이며 `--limit`도 가능합니다. 결과는 날짜 내림차순, 같은 날짜는 id 내림차순입니다.

| 검색 옵션 | 뜻 |
| --- | --- |
| --from / --to | 시작/종료일 포함. 한쪽만 지정해도 됨 |
| --category | 등록된 카테고리와 일치 |
| --type | income 또는 expense |
| --q | 메모 부분 일치, 대소문자 무시 |
| --tag | 태그 한 개의 완전 일치, 대소문자 구분 |
| --limit | 최대 출력 건수, 양수 |

여러 조건은 AND입니다. search에는 `--month`가 없으므로 월 검색은 날짜 범위로 지정합니다.

## 7. 월 요약과 예산: summary / budget

```powershell
& $ledgerPython -m budget_app summary --month 2026-11 --top 3
& $ledgerPython -m budget_app budget show
& $ledgerPython -m budget_app budget show --month 2026-11
```

summary에는 `--month YYYY-MM`이 필수이고 `--top` 기본값은 5입니다. 수입·지출·잔액, 카테고리별 지출 순위를 출력하며 거래 없으면 데이터 없음을 표시합니다.

예산을 실제로 설정하거나 갱신할 때:

```powershell
& $ledgerPython -m budget_app budget set --month 2026-11 --amount 10000
```

같은 월의 기존 예산은 바뀝니다. summary는 `지출 ÷ 예산 × 100` 사용률을 표시하고 지출이 예산보다 클 때만 경고합니다. 기존 실습에서는 지출을 삭제했으므로 다시 summary를 실행하면 과거 150% 출력과 달라질 수 있습니다.

## 8. 수정과 삭제: update / delete

먼저 list로 대상의 실제 id를 확인합니다. 아래 Read-Host는 PowerShell이 id를 물어보게 하므로, 안내 문구를 id로 잘못 저장하는 일을 줄입니다.

```powershell
& $ledgerPython -m budget_app list --limit 10
$expenseId = Read-Host '수정할 거래의 실제 TX- id를 붙여넣고 Enter'
& $ledgerPython -m budget_app update --id $expenseId --amount 12000 --memo 저녁
```

수정 가능한 필드는 `--date`, `--type`, `--category`, `--amount`, `--memo`, `--tags`입니다. 미지정 필드는 유지하고, 메모·태그는 `--memo "" --tags ""`로 비울 수 있습니다. 수정 필드를 최소 하나 지정해야 합니다.

삭제가 필요할 때만 다음을 실행합니다. 목록과 id를 다시 확인하세요.

```powershell
$deleteId = Read-Host '삭제할 거래의 실제 TX- id를 붙여넣고 Enter'
& $ledgerPython -m budget_app delete --id $deleteId
```

예전에 삭제한 id는 더 이상 사용할 수 없습니다. 없는 id는 오류와 힌트를 표시합니다. 사용자 화면의 성공 메시지는 실제 저장 성공 후에만 출력합니다.

## 9. 카테고리: category

```powershell
& $ledgerPython -m budget_app category list
& $ledgerPython -m budget_app category add
```

add 실행 후 `카테고리명:` 질문에 `hobby` 같은 이름만 답합니다. 삭제가 필요하면:

```powershell
& $ledgerPython -m budget_app category remove
```

`삭제할 카테고리명:` 질문에 삭제할 이름만 답합니다. 중복 추가, 사용 중인 카테고리 삭제, 마지막 카테고리 삭제는 거부합니다. 사용 여부는 특정 월이 아닌 전체 거래에서 검사합니다.

## 10. CSV 내보내기와 가져오기

```powershell
& $ledgerPython -m budget_app export --out practice-export.csv --month 2026-11
& $ledgerPython -m budget_app export --out food-export.csv --from 2026-11-01 --to 2026-11-30 --category food
```

export에는 `--out`과 최소 하나의 기간 조건이 필요합니다. `--month`와 `--from/--to`는 함께 지정하지 않습니다. category/type/q/tag도 지원합니다. 같은 출력 경로는 성공 시 기존 CSV를 교체하므로 필요한 파일 이름을 선택하세요. 거래 원본은 바뀌지 않습니다.

예제 CSV를 등록하고 싶을 때 **한 번만** 실행합니다.

```powershell
& $ledgerPython -m budget_app import --from examples/import.csv
& $ledgerPython -m budget_app search --from 2024-01-01 --to 2024-01-31
```

예제 날짜는 2024년 1월이고 정상 가져오기는 3건입니다. 같은 CSV를 다시 가져오면 새 id로 중복 등록됩니다. 한 행이라도 잘못되면 이번 가져오기 전체가 취소됩니다. 자세한 스키마는 [JSONL과 CSV 설명](./JSONL과%20CSV란/README.md)을 보세요.

## 11. 백업과 저장 경로·로그

```powershell
& $ledgerPython -m budget_app backup
Get-ChildItem .\data\backups
```

backup은 거래·카테고리·예산 JSONL 세 파일의 ZIP을 만듭니다. `[백업 완료] ...`는 출력이므로 명령처럼 입력하지 않습니다.

전역 옵션은 하위 명령 **앞**에 지정합니다.

```powershell
& $ledgerPython -m budget_app --data-dir ./practice-data category list
& $ledgerPython -m budget_app --data-dir ./practice-data --verbose list --limit 3
```

`--data-dir`는 별도의 저장 폴더를 선택하고, `--verbose`는 실행 시간·종료 코드 로그를 표준 오류에 표시합니다. practice-data와 기본 data는 서로 다른 자료이므로 평가 중에는 어느 폴더를 쓰는지 통일하세요.

## 12. 오류 코드와 전체 테스트

없는 id 조회 오류를 안전하게 확인하려면:

```powershell
& $ledgerPython -m budget_app delete --id NOT-EXISTING-TX
$LASTEXITCODE
```

실제 대상이 없는 id이므로 데이터를 지우지 않고 `1`을 반환합니다. `$LASTEXITCODE`는 바로 앞 외부 프로그램의 종료 코드입니다. 다른 Python 명령을 실행하기 전에 확인합니다.

| 코드 | 의미 |
| --- | --- |
| 0 | 정상 완료·도움말 |
| 1 | 입력·저장 데이터·파일 오류 |
| 2 | 필수 옵션 누락 등 명령 문법 오류 |
| 130 | EOF/Ctrl+C 입력 취소 |

전체 테스트는 가계부 하위 명령이 아니라 Python의 unittest 모듈을 실행합니다.

```powershell
& $ledgerPython -m unittest discover -s tests -v
$LASTEXITCODE
```

`Ran 30 tests ...`, `OK`, 종료 코드 `0`을 확인합니다. 테스트는 임시 폴더를 사용해 기존 평가 거래를 바꾸지 않습니다.

## 13. 자주 헷갈리는 입력 구분

| 화면/내용 | 해야 할 일 |
| --- | --- |
| PS C:\...> | 실행할 명령을 입력 |
| 날짜(YYYY-MM-DD): | 날짜만 입력 |
| 카테고리명: | 이름만 입력 |
| [저장 완료], [백업 완료] | 결과를 읽기. 다시 명령으로 입력하지 않음 |
| HELP의 ID, MONTH, OUT 등 | 설명 자리. 실제 값으로 바꿔 입력 |
